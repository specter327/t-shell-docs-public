# Demostraciones

Las demostraciones proporcionan evidencia visual de ejecuciones concretas de T-Shell y de los entornos utilizados para las pruebas.

Cada demostración conserva las capturas utilizadas como evidencia. Las imágenes se muestran directamente en esta página y cada miniatura enlaza con el archivo original.

> **Nota:** una demostración documenta una ejecución concreta. No constituye una garantía universal de compatibilidad ni una garantía para producción.
